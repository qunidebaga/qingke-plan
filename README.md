# 青稞计划 · 帮扶大学生自主创业计划

青稞计划官方网站，面向大学生创业者的帮扶平台，整合政府、高校、企业与社会资源，提供资金、培训、场地、政策四位一体的系统性支持。

## 站点结构

| 路由 | 页面 |
|---|---|
| `#/` | 首页（主视觉 Banner、计划规模数据、三大支持、最新动态、行动号召） |
| `#/about` | 关于我们（计划缘起、五年里程碑） |
| `#/programs` | 帮扶体系（种子基金、创业训练营、导师陪跑、共享工位、政策对接、投融资路演） |
| `#/partners` | 合作共建（共建伙伴、合作方式） |
| `#/join` | 加入我们（申请条件、加入流程、联系方式） |
| `#/apply` | 立即申请（申请表单，提交后整理信息发送至 105529978@qq.com） |

## 技术说明

- 纯静态站点：单入口 `index.html` + 原生 JS（`app.js`）hash 路由多视图
- 无构建步骤，无第三方运行时依赖
- 图片资源位于 `assets/images/`，相对路径引用

## 本地预览

直接双击打开 `index.html`，或在项目目录启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。
